# Behaviors

- **Navigation:** Desktop sidebar anchors scroll smoothly to page sections. Mobile view keeps a compact wordmark header; the full nav is intentionally hidden to preserve the reference's sparse, text-first feel.
- **Hover:** Links shift from the dark ink color to the burnt-orange accent. Sidebar links translate 3px to the right; resource links remain inline and change color only.
- **Responsive:** At 800px the fixed sidebar becomes a mobile header, the content becomes full width, multi-column layouts stack, and typography scales with viewport width.
- **Scroll:** Native smooth scrolling is enabled through `html { scroll-behavior: smooth; }`. No scroll-triggered state changes, sticky content, or carousels were observed.
- **Content states:** All sections are static. External-looking resource links intentionally point to the contact anchor in this fictional design study.
