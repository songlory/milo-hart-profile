# Page Topology

1. Fixed desktop sidebar with wordmark, short descriptor, numbered anchors, availability status, and fictional-profile notice.
2. Responsive mobile header replaces the sidebar below 800px.
3. Hero profile section with orange monospaced eyebrow, oversized serif-accented name, short positioning statement, and contact links.
4. Practice statement section with three principles in a ruled grid.
5. Notes section with reverse-chronological entries and inline action links.
6. Selected work section with year, title, type, description, and resource links.
7. About section with a large statement column and compact biographical copy.
8. Contact footer with question-led CTA, email, social links, and small metadata footer.

The page is static and anchor-driven. There are no dialogs, tabs, backend actions, or external assets. Hover behavior is limited to color and small navigation translation changes.
