# FictionalProfile Specification

## Overview
- **Target file:** `src/app/page.tsx`
- **Interaction model:** static content with anchor navigation and hover states
- **Reference:** `https://bhanml.github.io/`

## Visual language
- Warm off-white page background (`#f7f7f3`), near-black ink (`#171816`), muted gray-green secondary copy, burnt-orange accent (`#d86a43`), and thin low-contrast rules.
- Text-first profile layout. The reference's academic density is translated into a personal archive with Notes, Selected work, About, and Contact.
- Desktop uses a fixed 280px sidebar and a centered reading column. Mobile collapses to a simple top header at 800px.

## Content
- Identity is entirely fictional: Milo Hart, writer, builder, and curious observer.
- A visible “Fictional profile / design study” note prevents the page from being mistaken for a real person's biography.
- Projects and notes are invented and intentionally generic.

## Responsive behavior
- Desktop: sidebar + content column; hero and supporting metadata use a two-column grid.
- Mobile: full-width content, stacked grids, compact header, fluid display typography.
